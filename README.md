# Digital Studio

Многостраничный сайт студии продвижения в геосервисах и разработки сайтов.

## Запуск

```bash
pnpm install
pnpm dev
```

## Проверки

```bash
pnpm run lint
node --test tests/calc.test.mjs
```

## Основные разделы

Главная, услуги, кейсы, геомаркетинг, о компании, этапы работы, калькулятор, вопросы и контакты.
